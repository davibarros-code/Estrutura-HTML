Guia básico de HTML

Conheça a estrutura e alguns elementos usados para organizar o conteúdo de uma página.

Entendendo head e body

Na seção <head> ficam informações sobre o documento, como o título da página e metadados. O conteúdo visível, como textos, imagens e links, fica na seção <body>.

Hierarquia de títulos

Os títulos vão de <h1>, o nível principal, até <h6>, o nível mais específico. Use-os para organizar o assunto em uma ordem lógica, não apenas para mudar o tamanho do texto.

Esta página tem um único <h1> como título principal e usa <h2> para os títulos das seções.

Tags semânticas

Tags semânticas descrevem a função do conteúdo e ajudam navegadores e tecnologias assistivas a compreender a estrutura da página.

  • <header>: introdução ou cabeçalho da página ou de uma seção.
  • <nav>: grupo de links de navegação.
  • <main>: conteúdo principal da página.
  • <section>: agrupamento temático de conteúdo.
  • <article>: conteúdo independente, como uma notícia ou publicação.
  • <footer>: informações finais da página ou de uma seção.

Links e imagens

O elemento <a> cria links para outras páginas, arquivos ou partes da página. O texto do link deve indicar claramente o destino.

O elemento <img> insere uma imagem. O atributo alt oferece uma descrição textual quando a imagem não pode ser vista ou carregada.

Listas e tabelas

Listas organizam itens relacionados. Use uma lista não ordenada quando a sequência não importa:

  • <header> para o cabeçalho.
  • <main> para o conteúdo principal.
  • <footer> para o rodapé.

Use uma lista ordenada quando os itens tiverem uma sequência:

  1. Abra o documento HTML.
  2. Organize o conteúdo dentro do <body>.
  3. Salve o arquivo e abra-o no navegador.

Tabelas apresentam dados relacionados em linhas e colunas. Não devem ser usadas para montar o layout da página.

Matemática e química

Em HTML, as tags <sub> e <sup> ajudam a representar números abaixo ou acima da linha do texto.

Na química, o subscrito indica a quantidade de átomos: a água é representada por H2O e o dióxido de carbono por CO2.

Na matemática, o sobrescrito pode representar uma potência: 23 = 8.

Esses elementos são adequados para exemplos simples. Expressões matemáticas mais complexas podem ser representadas com MathML.

Acessibilidade e boas práticas

A acessibilidade ajuda pessoas com diferentes habilidades e formas de navegação a compreender e usar a página.

  • Organize o conteúdo com títulos em uma ordem lógica.
  • Use textos alternativos que descrevam imagens informativas.
  • Associe cada campo de formulário a um rótulo claro.
  • Escreva links com nomes que expliquem para onde levam.
  • Não use apenas cores para transmitir informações.
  • Teste a navegação usando o teclado e verifique se os controles são fáceis de identificar.
